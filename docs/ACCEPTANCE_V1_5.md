## 新浏览器测试不再只是离线HTML

`tests/supervision_render.py` 自行启动一个仅绑定127.0.0.1随机端口的测试服务，浏览器通过真实HTTP请求访问页面和接口；后端调用实际Worker处理器，数据库使用独立的Node/SQLite事务适配器。服务在测试结束时停止，不是部署命令。测试不解除CSP、绕过浏览器网络限制或使用真实账号。

320×700、390×844、768×1024、1440×1000检查五个新页面及长表单，包含成果位置、输入转义、变更原文、个人分担和规则默认状态。使用三个独立浏览器会话完成：

- 本人阅读报告，不改变阶段或共同决策。
- 从真实表单提交500元追加；承担人不勾选则不能确认，三名合伙人分别同意后只增加预算，不增加现金或改变比例。
- 提交新的阶段成果，由指定另一人验收，再由三名成员分别确认阶段关闭；下一阶段不自动开放。
- 异常先说明原因/安排，再提交结果，由另一人复核关闭，负责人不能自关。

这证明上述真实前端和接口能在本地适配器下协同运行，**不证明生产Workers/D1配额、真实设备、外部模型、银行资金或通知送达已经验收**。其余旧UI脚本仍使用明确的离线HTTP替身，不能与新测试混写成所有页面均云端端到端通过。

## 后端主要覆盖

旧项目不因升级被自动启用监督；三人规则会签与停用；报告快照、阅读、更正与审计；错误角色/未来日期/外项目附件；过旧周期不伪装新进展；独立验收、数据变化失效、旧阶段报告拒绝；新旧计划对比及字段白名单；提前开放例外与原阶段状态保留；个人出资明确确认与预算/现金/比例分离；幂等及并发登记不超分担；关联已有流水不重复增加现金；反向更正降低完成金额；旧事实变化使追加最后一票失败；未到账取消扣回预算；追加到期复盘与到账提醒分离；异常不能自关或伪称已消除；严重限制不阻止已发生付款；真实调度并发去重、站内通知与审计；归档只读和完整导出。

npm test

# 安装开发依赖后，构建但不部署：
npx wrangler deploy --dry-run --outdir artifacts/worker-build

UI命令需要自行安装Python Playwright、可执行Chromium与Node。`CHROMIUM_PATH`指定浏览器，本轮使用`/snap/bin/chromium`；脚本默认`/usr/bin/chromium`。新HTTP测试生成的临时文件、测试账号和截图在被Git忽略的`artifacts/`，不应拿去生产使用或上传真实数据。

旧测试脚本仍输出历史文件名；本轮把真实重新运行结果另存v1.5.0文件并标明runVersion和测试方式。没有用旧报告冒充本次测试。管理员测试等待真实close事件后检查输入清空；中转测试调整为当前基线已取消原因/根密钥要求的界面，不削弱生产权限断言。
