## 重点测试用例

多人流程：三账号共同确认基准；通知/已阅不批准；单人重复批准不凑人数；要求补充会阻塞；全体签齐；反对不通过；改版使旧签名失效；下一阶段不开不能采购。

资金与执行：并发申请不突破阶段预算；同供应商拆单提示；收款对象不符被拒绝；已下单不改原单；同一幂等付款并发重放只一次；超额付款被拒绝；登记人不能复核自己；独立验收、累计数量不能超购；未经批准的真实支出仍入账；未核实流入不能采购。

规则变更：任何合伙人可暂停新增采购；正式计划不能由管理员直接改；预算变更重置未下单采购；退出需要本人在内全员确认；退出者可投最后一票；增加合伙人重新冻结名单；第31名合伙人提前被拒绝，避免会签卡死。

财务：出资/借款不计利润；结算期间账目变化使旧结算不能生效；人民币分摊尾差守恒；分红不能超批准金额；更正追加且不可重复；对账要求余额和复核情况匹配。

安全：匿名/其他项目成员不能读取项目及附件；CSRF、Origin；不能重复初始化；新会话不继承旧的重验证；内部操作不能伪造；整数金额；附件真实字节hash；拒绝HTML/SVG；跨项目附件引用拦截；CSV防公式注入；CSP/HttpOnly/禁止API缓存；篡改状态导致审计校验失败。

通知：官方RPC签名样例；Webhook SSRF白名单；未配置不伪装成功；并发发送租约防重复；企业微信限流退避；短信服务商接受保存回执；超时标记不确定不盲重发；每日去重；大量任务游标不使后排提醒饥饿。

## 修复过的问题

相同付款幂等键的并发提交最初导致回执UNIQUE冲突，已改为每次CAS提交尝试独立guard并回归；附件hash已改按真实字节计算；退出者最后一票的权限返回已修正；手机网格表格导致页面横向溢出已修复；提醒已增加批次/条目游标；合伙人数上限在新增前拦截。

## 验证边界：没有伪装完成的项目

**没有运行官方Wrangler/Miniflare或者部署到真实Cloudflare。** 交付环境不能访问npm注册表，无法安装Wrangler；因此没有编造bundle大小、云端CPU、平台查询配额或dry-run成功记录。代码采用查阅过的官方绑定API，兼容性仍需在目标环境实测。

**没有完成浏览器到本地API的在线端到端联调。** 此处托管Chromium阻止localhost导航，返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。没有修改/绕过策略。页面测试使用真实本地业务数据的无秘密静态快照、原前端代码和离线fetch替身，只验证渲染/导航/表单/布局。API业务行为由另一组Node测试独立验证，不能将两组相加称作完整浏览器E2E。

**没有发送真实企业微信/短信。** 渠道测试使用模拟响应；真实账号授权、签名模板审核、用户同意、服务商回执和设备收信需要上线时另测。

**没有执行银行接入、实际付款、税务或外部独立审计。** 这些不是第一版功能。

**没有全面渗透测试、负载测试、故障注入或多人自然人身份验证。** 已有用例覆盖关键业务，不保证所有缺陷已发现。第一版应先在独立试运行项目验收，再逐步用于真实合作。

## 重跑本地检查

```bash
npm run check
npm test
```

离线视觉检查需要Python Playwright和Chromium：先在空白本地实例运行演示，再导出无秘密快照。

```bash
npm run dev
# 另一个终端，仅空白本地实例
npm run demo
npm run fixture:visual
python tests/browser_render.py
```

`CHROMIUM_PATH` 可指定实际Chromium路径，默认 `/usr/bin/chromium`。需要先在允许安装的环境准备Playwright依赖。`artifacts/`只保存测试输出，不提交真实用户数据。

可运行浏览器在线联调的环境中，另有 `python tests/browser_smoke.py`，仅允许localhost演示账号；它会提交演示第三票、创建测试任务，不能指向正式站点。该脚本本次没有通过在线执行，不能作为已完成证据。
