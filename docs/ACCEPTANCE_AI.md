## 复现

```bash
npm run check
npm test
```

可选离线界面检查（需Python Playwright及Chromium，不能以安装成功代替测试）：

```bash
node tests/ai-browser-server.mjs
# 该测试专用进程生成 artifacts/ai-visual-fixture.json，模型请求使用测试替身。
# 在另一终端运行，完成后停止自己启动的测试进程：
python3 tests/ai_browser_render.py
```

测试服务绑定localhost:8799；不要公开暴露测试服务。它不是正式部署方式、不是Cloudflare官方模拟器，也不能连接生产数据库。本次托管浏览器访问localhost被环境策略拦截（ERR_BLOCKED_BY_ADMINISTRATOR），遵守限制，改做不依赖网络的离线渲染，**没有完成浏览器到后端在线全流程**。
