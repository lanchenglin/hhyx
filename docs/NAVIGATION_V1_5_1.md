# v1.5.1 · 侧边栏分组整理

基线：`main` 的 `da6a8e088074ed57fb7c9913d8085fdc8fe017f8`（v1.5.0）。本轮仅修改前端导航、样式、测试和说明；后端业务、数据库、权限、密码/MFA、AI配置与原采购会签均不变。

## 新的导航

| 分组 | 原功能入口（全部保留） |
|---|---|
| 项目总览 | 出资人总览、业务总览 |
| 计划与执行 | 阶段与计划、分工与任务、简短汇报与成果、计划变更 |
| 资金与决策 | 支出与会签、追加投入、共同决策、财务与结算 |
| 风险与分析 | 异常处理、AI分析 |
| 合作与资料 | 成员与资料、移交与退出、审计记录 |

通知中心移至账号区域上方；账号设置、账号安全、退出登录及仅管理员可见的系统管理仍保留。共16个原项目页面，没有删功能或合并业务数据。两个总览放在同一分组内，出资人视角与业务细节仍可分别查看。

默认只展开当前页面所在分组，展开另一组会收起之前一组，减少菜单长度。页面切换、原链接直达及项目切换会自动定位分组；当前页高亮并带 `aria-current=page`。折叠状态仅保留在当前页面运行内存，不新增服务端偏好或浏览器持久化内容。普通刷新仍按原应用路由规则处理；带project/tab的原直达链接保留。

新增页面使用各自的图标，不再因为缺少图标统一显示成勾号。支出和共同决策旁的数字表示项目当前待会签记录数；通知数字表示当前项目已读取列表中的未读通知数，不代表这些事项已经完成或已被某个人批准。

桌面正常高度下只有中间菜单区滚动，项目切换与账号区保持可达。手机继续使用原抽屉和遮罩，选择页面后自动关闭；小高度/横屏下整个侧边栏可以滚动，不以隐藏控件来消除溢出。原归档只读和角色权限不变。

采用原生details/summary折叠，支持点击、Enter与空格；手机焦点限制也包含分组标题。没有把页面导航改成需要特殊方向键操作的菜单组件。未选择项目时显示提示，系统管理和账号入口仍可用。

## 复现与升级

```bash
npm run check
npm test
npm run test:navigation-ui
npm run test:supervision-ui
```

浏览器测试需现有Python Playwright及Chromium，使用 `CHROMIUM_PATH` 指定浏览器，`NODE` 可指定Node入口。测试服务只监听127.0.0.1随机端口，完成后关闭，不是生产启动方式。其余回归按各脚本要求先生成合成fixture。

从v1.5.0升级无需新增数据库迁移，不重建账号，不调整监督规则或AI授权。备份后保留真实域名、数据库/对象桶绑定及部署配置，更新本次代码并重新部署Workers静态资源即可；不要用仓库占位配置覆盖生产设置。`1` 分支保持旧版，不合并本次导航更新。
