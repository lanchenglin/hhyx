# 手机 Web 适配与验收 · v1.1.1

> **v1.2.0更新：** 已加入系统管理员后台、归档/回收站、用户权限与网页AI配置。以下早期版本内容需结合 `ADMINISTRATION.md` 阅读；升级必须应用0003，不能只替换前端。旧密码保留，管理员不能代签，已发生业务不物理删除。

手机和电脑使用同一个网站、同一账号和同一项目数据；不是独立小程序，也不是将电脑截图缩小显示。手机上的可见内容和操作权限与电脑相同，AI 仍无审批权，采购仍须全体必签合伙人确认。

## 本次实现

| 区域 | 手机表现 |
|---|---|
| 项目导航 | 可滚动的抽屉导航，明确关闭按钮、遮罩点击关闭、Escape 与键盘焦点限制；打开时背景不可操作。切换项目或返回宽屏后释放背景锁定。 |
| 看板与长内容 | 手机指标按屏宽重排；极窄屏改为单列。标题、供应商、备注、文件名等可换行；金额不省略、不用隐藏溢出来掩盖问题。 |
| 采购/财务/成员等明细 | 600px 及以下，简单表格转换为带字段名的卡片，保留全部单元格。复杂合并表格仍保留有标签的横向滚动区域。 |
| 采购会签 | 每个人的意见、已阅状态、当前版本、2/3 等会签进度和三种表态均保留；常用按钮至少44px高。 |
| 新建、修改和身份核验 | 760px 及以下使用全屏表单；头部与底部操作区域保留，中间内容可滚动。长表单不再挤进桌面式小弹窗。 |
| AI分析 | 项目/采购/阶段三个入口、发送预览、来源快照、风险处置、人工转任务都适配窄屏。确认复选框不默认勾选。 |
| 输入和安全区 | 普通输入文字16px；金额使用小数输入模式，数量使用数字输入模式。声明安全区并保留用户缩放；使用动态视口和VisualViewport处理可用高度变化。 |
| 本地与云端入口 | 新增`public/mobile.css`，同时加入本地开发适配器的资源列表，避免本地请求CSS时误返回HTML页面。生产静态资源仍由Workers Assets提供。 |

底部没有新增可绕过确认的“快速批准”。页面首次打开表单时先聚焦标题，不自动弹出键盘或提交。身份核验仍需当前账号本人输入密码。

## 如何使用

部署新版本后，手机浏览器打开与电脑相同的正式站点地址并登录。左上角导航按钮用于进入项目总览、采购、财务、AI分析等页面；项目下拉框用于切换合作项目。手机没有单独的数据库或单独一份采购记录。

本版本不增加PWA、离线编辑或自动同步队列：实际读取与提交仍需要网络。浏览器/微信内置浏览器下载凭证的行为由客户端决定，手机真机验收时应测试自己的常用浏览器。

## 已执行的本地测试

以下为源码回归与离线浏览器渲染，不等于手机真机或Cloudflare上线测试。

- 新手机/平板/桌面回归：**56项通过，无pageErrors**。`test-results/mobile-render-results-v1.1.1.json`记录完整清单。
- 屏宽/高度：320×700、360×800、390×844、430×932、667×375（横屏）、768×1024、1440×1000；每个尺寸检查10个主要页面。
- 额外检查：390×390短视口、两个项目切换、超长无空格名称、遮罩与焦点释放、三种会签决定、身份核验、采购长表单、AI发送预览/来源/转任务，以及登录页。
- 既有AI离线界面回归：11项通过，无pageErrors。`test-results/ai-browser-render-results-v1.1.1.json`记录结果。
- 全部Node测试：**95项通过，0失败、0跳过**（既有92项+新增3项静态资源测试）；JavaScript语法检查28个文件通过。结果见`test-results/node-test-results-v1.1.1.txt`及`test-results/check-v1.1.1.txt`。

浏览器数据由真实本地Worker处理器生成，模型使用明确测试替身；浏览器fetch使用离线替身。没有向真实模型、Cloudflare或通知渠道发送请求。短视口只检查小高度下的布局，不代表实际iOS/安卓软键盘已验证。截图都是虚构测试项目。

复现：

```bash
npm run check
npm test
node tests/mobile-fixture.mjs
npm run test:mobile
```

最后一步需要Python Playwright及Chromium；使用`CHROMIUM_PATH`指定浏览器位置，默认`/usr/bin/chromium`。测试脚本不安装依赖，也不改变浏览器/环境访问策略。生成的测试数据和截图位于被Git忽略的`artifacts/`。

## 升级与上线验收

从v1.1.0升级到v1.1.1不新增数据库迁移，不需要清库、重建账号、更改模型密钥或重做原AI授权。备份后保留现有`wrangler.jsonc`、域名、绑定、Secrets与本地配置，按`HERMES_DEPLOY.md`更新代码并重新部署；不要用模板覆盖实际配置。

从v1.0.0升级的站点仍须先按既有说明执行`0002_ai_analysis.sql`；手机适配并没有取消AI版本的迁移要求。

上线后至少用自己的iPhone Safari、安卓Chrome及常用微信内置浏览器检查：登录/接受邀请、开关导航、切换项目、阅读金额和会签记录、三种意见提交及身份验证、键盘弹出后的输入与提交、上传/下载凭证、AI报告及来源、横竖屏切换。多人会签用各自的独立测试账号，不能代替真实合伙人批准业务。

这些真机、真实网络、Cloudflare和真实AI联调没有在本次环境完成，部署报告不得将它们写为通过。
