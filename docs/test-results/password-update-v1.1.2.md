# v1.1.2 密码显示开关验收

日期：2026-09-27。基于远端 v1.1.1（6d7dcf4）开发；已逐文件核对本地测试版本与提交版本的 SHA-256。远程提交工作目录没有 Node，因此测试在本次隔离工作容器中执行，不冒充服务器或云端测试。

## 实际执行结果

- `npm run check`：29 个 JavaScript 文件语法检查通过。
- `npm test`：96 项通过、0 失败、0 跳过，耗时 128500ms。包含新增的密码修改安全回归：未验证本人时禁止修改、拒绝短密码、新密码可登录、旧密码和其他登录会话失效、其他成员账号不受影响。
- `npm run test:password-ui`：21 项离线 Chromium 交互检查通过，无 pageErrors。覆盖 320×700、390×844、1440×1000；完整逐项结果见同目录 `password-visibility-results-v1.1.2.json`。

界面检查包括：当前密码与新密码默认隐藏；点击、Enter 和空格切换只改变可见性，不发网络请求、不提交表单、不改变值/选区或写入本地存储；正确的输入标签和按钮关联；按钮至少44px；取消/关闭清空，重新打开隐藏；留空不请求修改；模拟提交失败后隐藏但保留输入；成功提交原值后清空。截图仅为合成测试输入，不是用户真实密码。

## 实现与边界

只针对本人身份验证框和账号设置的新密码框，不增加已保存密码查询、他人密码查看或找回明文功能。新密码仍由原来的后端接口验证和存储，没有修改服务端、采购会签或 AI 权限逻辑。v1.1.1 升级无需新增数据库迁移。

浏览器测试运行真实前端，但 HTTP 使用显式测试替身；后端回归调用真实 Worker 源码及本地 SQLite 适配器。未进行真实账号操作、Cloudflare 部署、iPhone/安卓真机或手机软键盘测试。须重新部署后，线上页面才会出现开关；请在自己的常用浏览器完成真机验收。
