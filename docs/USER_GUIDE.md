# 使用说明与业务规则

## 角色与知情范围

每位参与人使用自己的账号。合伙人能参与所有采购和共同决策；执行成员处理其职责内的任务/采购；只读成员仅查看。第一版同一项目的已加入有效成员都能看项目计划、采购、财务和审计，不做字段级财务隔离。需要隔离的外部供应商不要邀请为成员。

创建人负责筹备和技术渠道配置，不拥有强制通过采购的业务权力。平台识别的是不同账号，不能证明自然人身份；禁止共用或代管合伙人密码。

## 计划与阶段

筹备阶段由创建人编辑，并以“合作基准计划”让全体合伙人确认。有人尚未接受邀请，不能开始会签。至少需要两名合伙人，比例合计100%。基准会签期间锁定筹备计划，修改先撤回。

阶段包括名称、预算、目标、验收标准及截止时间。只有已开放阶段可以申请采购；关闭阶段需要满足其执行事项检查，开放后续阶段须前阶段完成并提交依据。全员表态是明确的系统决策记录，不等于第三方数字签章。

基准生效后，预算、分配比例、合作条款、人员、阶段及分工变更走“共同决策”。同一时刻只有一项待处理共同决策，防止相互覆盖。任何人反对则该轮不通过；未回复永远不算同意。对话讨论不能替代表态。

## 采购从申请到收货

创建采购时写清所有商品、数量、单价、供应商、收款对象、付款条件、报价依据、用途、风险、退货方案和日期。运费等另列一行，避免隐藏在总额之外。数量只支持正整数；需要按重量采购时用最小整数计量单位表达并注明规格。

指定执行人和**不同的验收人**。提交后冻结全部已加入合伙人的名单，立即占用阶段预算及可用资金；这并非已经花钱，而是防止并行申请重复使用同一额度。

每人可确认已阅、同意、不同意、要求补充，或留言。只有明确同意才计入通过人数。要求补充会阻止该成员通过；反对导致该轮被拒绝。申请人也是合伙人时也必须单独点同意，提交申请本身不自动投票。

修改商品、金额、供应商、付款条件等内容会生成新版本，保留旧版记录、清空旧签名和已阅状态，重新提交。新一轮批准有效期由该版本确定，过期不能直接下单；需要更新版本再次会签。过期申请不会悄悄自动释放已占预算，主动复核后撤回或改版。

全员同意、阶段/总预算有空间、核实资金足够并保留最低安全金额，三道检查都通过才可登记下单。单次/累计付款不能超过批准金额，收款对象必须一致。付款登记是录入真实已发生事实，不是调用银行付款。

已经形成订单后，不能用“编辑采购”把历史订单变成另一笔交易。变更需要有单独依据和相应新决策。第一版没有完整的已下单订单修订、退货退款冲销工作台；实际退款可登记并说明关联单号，由另一人核对，不得直接删原付款。复杂修订先暂停扩张并导出完整资料处理。

同阶段同供应商的已有采购会提示核查拆单。第一版是确定性提醒，不是能识别所有关联供应商或恶意拆单的智能风控。

## 已发生的违规支出

没经过批准却实际花出去的钱，要立即在“财务与结算”登记，并勾选未经事前批准，提供事实说明、阶段及凭证。系统会显示异常并保守扣减资金。不能用拒绝入账来让账面变好看。

这个标记不自动认定法律责任，也不决定由谁赔偿。未登记或伪造的事实，软件不能凭空发现。实际支付权限仍需线下控制。

## 财务口径

本版是单币种人民币的内部经营管理账，全部金额用整数分保存。

- 已登记现金余额：所有上报现金流入减现金流出，不等于已核实。
- 已核实现金余额：仅计算另一名合伙人复核过的记录。
- 保守资金：未核实的现金流出立即扣除；未核实流入不增加可采购额度。
- 可用于新安排：保守资金减未付采购承诺、已批准未付分配、最低保留资金及手工未付费用。
- 内部估算利润：已复核收入/应收收入，减已复核费用、已登记销售成本和减值。出资/借款不当利润；库存采购付款不直接全算费用。

每条账目由登记人以外的合伙人复核。更正追加反向记录，原记录仍留存。采购付款和分配有专用状态约束，不支持普通反向记录直接篡改它们；真实退款另行登记并核查。

应收应付目前是手动累计口径，不是逐发票账龄/销账系统；库存没有SKU、仓位、自动成本结转或盘点账。利润、退款影响和税费需要按约定口径完整登记后复核，不能只登记销售收入就直接分红。未纳入的成本不会被软件猜出来。

“资金支出预占用”包含有效采购及标为未经批准的实际现金支出；手工应付会减少可用现金，但不构成完整的全科目预算控制。不得把该指标当成总账全部承诺统计。

## 对账与分配

共同对账需要记录实际账户余额、凭证及说明；系统检查与已复核账目一致并冻结本轮账目摘要。会签期间账目变了，最后一票不能把旧对账当成新事实，应重新提交。

结算也冻结账目摘要、金额、成员与比例，逐人确认。系统检查全部记录已复核、金额不超过内部估算可分配结果和保守现金。人民币分摊使用整数分与余数补齐，防止合计差几分钱。实际分配后另登记付款并复核。

这些检查只对已录入资料成立，不能替代会计核算、税务处理或真实资金核对。

## 暂停、退出和记录

任一合伙人可紧急暂停新增采购。暂停后仍可记录已发生付款、验收和财务事实，不能用暂停来隐藏现有债务；恢复由全体合伙人确认。

移除合伙人也要包含其本人的共同批准。执行中职责、未完成任务、待付分配等须先处理。当前版本不支持移除创建人、强制退伙、账号继承或自动仲裁；有人失联时不提供管理员绕过审批按钮。

项目预算、成员、比例及条款变更通过后，未形成订单的待会签/已批准采购被重置为新草稿，须在新规则下再次提交；已形成订单的事实保留。

重要操作（批准、付款、复核、暂停等）需近期重新输入本人密码，验证只在当前会话5分钟有效。

审计页可校验记录链、导出项目JSON和账目CSV。JSON中的附件条目是目录，文件需另行下载备份。保留不同日期的独立副本，不能只保存一份会被覆盖的导出。
