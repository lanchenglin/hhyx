## 复现

```bash
npm run check
npm test
npm run test:admin-ui
node tests/mobile-fixture.mjs
npm run test:mobile
npm run test:password-ui
npm run fixture:ai
python3 tests/ai_browser_render.py
```

浏览器命令需要Python Playwright与Chromium，默认 `/usr/bin/chromium`，可设置CHROMIUM_PATH。测试脚本不安装依赖或绕过网络策略；fixture:ai不启动HTTP服务器。临时数据和截图在被Git忽略的artifacts中，不可混入真实资料。
